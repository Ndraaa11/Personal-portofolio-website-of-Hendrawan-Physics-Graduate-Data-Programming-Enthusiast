Prediksi dan Optimasi Zona Hambat Kitosan menggunakan Artificial Neural Network

Proyek penelitian yang menerapkan Artificial Neural Network (ANN) untuk mempelajari hubungan antara jumlah koloni Staphylococcus aureus, konsentrasi kitosan, dan zona hambat berdasarkan dataset penelitian.

Python Machine Learning Artificial Neural Network Data Analysis

PROJECT OVERVIEW

About This Project

Proyek ini merupakan penelitian berbasis data yang menerapkan Artificial Neural Network (ANN) untuk mempelajari hubungan antara jumlah koloni Staphylococcus aureus, konsentrasi kitosan, dan zona hambat berdasarkan dataset penelitian.

Dataset terdiri dari 60 observasi dengan dua variabel input dan satu variabel target. Proses analisis mencakup data preparation, transformasi data, pembagian dataset, standardisasi, pemodelan ANN, serta evaluasi performa model menggunakan MSE dan R².

Model kemudian digunakan untuk melakukan prediksi dan mengeksplorasi kombinasi variabel input dalam ruang data yang diamati.

Project Objective

Membangun model Artificial Neural Network untuk memprediksi zona hambat berdasarkan jumlah koloni dan konsentrasi kitosan serta mengeksplorasi pola hubungan antarvariabel dalam dataset.
